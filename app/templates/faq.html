FAQ

This page will be updated regulary as any new information or features are added

How does this work?

For every game in the 2026 World Cup, predict the result on the "Upcoming Games" page.
Simply enter a number into the correct boxes then hit "Submit Predictions", we'll handle the rest!
Based on your predictions you'll earn points, and you can see how you stack up on the "Leaderboard" page.

When can I predict games?

Every game can be predicted up until the minute it starts (GMT), anything past this won't be counted.
There's no requirement to do all the games at once either, but be careful not to forget!

What if I want to change a prediction?

At the bottom of the "Upcoming Games" page, games that you've already predicted that haven't yet happened can be updated.

How often are scores updated?

Scores should be updated roughly once a day during the tournament, however the calculation isn't automatic and relies on an admin (me) pressing a button that you can't see, so it won't always be at precisely the same time.

How are my scores calculated?

For group games

  • 5 points for correct score
  • 2 points for the correct result
  • 1 bonus point if you predict one of the correct scores
Examples:
Prediction: Scotland 5 - 0 England
Actual Score: Scotland 5 - 0 England
Awarded: 5 points (Correct Score)

Prediction: Scotland 2 - 1 England
Actual Score: Scotland 5 - 0 England
Awarded: 2 points (Correct result)

Prediction: Scotland 5 - 0 England
Actual Score: Scotland 3 - 0 England
Awarded: 3 points (Correct result and a bonus point for a correct score, 0 England)

Prediction: Scotland 1 - 1 England
Actual Score: Scotland 2 - 2 England
Awarded: 2 points (Correct result)

For knockout games

When predicting a win in regular or extra time:

  • 5 points for the correct score
  • 3 points if you predict the correct result
  • 1 bonus point if you predict one of the correct scores
Examples:
Prediction: Scotland 5 - 0 England
Actual Score: Scotland 5 - 0 England
Awarded: 5 points (Correct Score)

Prediction: Scotland 2 - 1 England
Actual Score: Scotland 5 - 0 England
Awarded: 3 points (Correct result)

Prediction: Scotland 5 - 0 England
Actual Score: Scotland 3 - 0 England
Awarded: 4 points (Correct result and a bonus point for a correct score, 0 England)

Prediction: Scotland 1 - 1 England
Actual Score: Scotland 2 - 2 England
Awarded: 3 points (Correct result)

When predicting a win on penalties:
  • 3 points for the correct score
  • 2 points for the correct result
  • 2 bonus points for the winner on penalties
Examples:
Prediction: Scotland 2 - 2 England - Scotland penalty winner
Actual Score: Scotland 2 - 2 England - Scotland penalty winner
Awarded: 5 points (3 points for the correct score and 2 bonus points for the correct penalty winner)

Prediction: Scotland 2 - 2 England - Scotland penalty winner
Actual Score: Scotland 1 - 1 England - Scotland penalty winner
Awarded: 4 points (2 points for the correct result and 2 bonus points for the correct penalty winner)

Prediction: Scotland 2 - 2 England - Scotland penalty winner
Actual Score: Scotland 2 - 2 England - England penalty winner
Awarded: 3 points (3 points for the correct score but 0 bonus points for the incorrect penalty winner)

Prediction: Scotland 2 - 2 England - Scotland penalty winner
Actual Score: Scotland 1 - 1 England - England penalty winner
Awarded: 2 points (2 points for the correct result but 0 bonus points for the incorrect penalty winner)
